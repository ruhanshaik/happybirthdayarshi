# A Little Surprise for Arshi

Vite + React + TypeScript + Tailwind + Framer Motion.

    npm install
    npm run dev
    npm run build

Content: src/data/birthdayMessages.ts. PIN, name, date, timings: src/data/sceneConfig.ts.
The PIN is a playful client-side gate, not real security. Music is optional and synthesized.
